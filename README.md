# 🎤 AI Live Meeting Summarizer

An end-to-end AI-powered system that records, transcribes, analyzes, and summarizes meetings.
This project is developed in multiple stages to build a complete intelligent meeting assistant.

---

# 🚀 Features

## ✅ Audio Processing

* Upload audio files (`.wav`, `.mp3`)
* (Optional) Live recording support

## 🧠 Speech-to-Text

* Transcription using **Whisper (OpenAI)**
* Accurate speech recognition

## 👥 Speaker Diarization

* Identifies multiple speakers
* Generates speaker-wise transcripts

## 📌 Meeting Summarization

* Extracts key points from long conversations
* Generates concise summaries

## 📄 Export Options

* Download transcript & summary as:

  * Markdown (.md)
  * PDF (.pdf)

## 📧 Email Integration

* Send transcript & summary via email

## 🌐 Web Interface

* Built using **Streamlit**
* User-friendly UI for interaction

## 🚀 Deployment

* Deployed on Render
* Accessible via web browser

---

# 🏗 Project Stages

## Week 1 – Audio Recording

* Record meeting audio
* Save as `.wav`

## Week 2 – Speech-to-Text

* Convert audio to text using Whisper

## Week 3 – Speaker Diarization

* Identify speakers
* Generate speaker-wise transcript

## Week 4 – Summarization

* Convert transcripts into meaningful summaries

## Week 5 – Backend Integration

* Combine all modules into pipeline

## Week 6 – Streamlit UI

* Build interactive frontend
* Upload and process audio

## Week 7 – Final Features

* Email integration 📧
* PDF/Markdown export 📄
* Deployment 🌐
* Full end-to-end system
